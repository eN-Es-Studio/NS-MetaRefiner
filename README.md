**NS MetaRefiner** adalah sebuah aplikasi cerdas berbasis Windows yang dirancang khusus untuk memproses, menyaring, dan menyusun metadata file secara otomatis dan terorganisir demi alur kerja yang lebih efisien.

## 🛠️ Fitur Utama
- **Intelligent Metadata Processing**: Membaca dan menyaring informasi metadata file dengan akurat.
- **Automated Sorting**: Mengurutkan dan memindahkan file ke dalam folder tujuan berdasarkan kriteria metadata yang ditentukan.
- **Windows Optimized**: Berjalan mulus dan ringan di platform Windows dengan performa maksimal.

## 📦 Cara Install & Penggunaan
1. Unduh rilis terbaru dari tab *Releases*.
2. Ekstrak file ZIP di komputer Anda.
3. Jalankan file `NS-MetaRefiner.exe`.
4. Pilih folder sumber file dan tentukan aturan penyaringan metadata Anda.
